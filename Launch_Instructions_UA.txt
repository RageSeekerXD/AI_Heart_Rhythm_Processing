==============================================================================
        ІНСТРУКЦІЯ ЗАПУСКУ ЗАСТОСУНКУ «РОЗПІЗНАВАННЯ СЕРЦЕВОГО РИТМУ»
==============================================================================


1. Призначення
--------------

Застосунок генерує послідовності частоти серцевих скорочень (ЧСС) для
нормального ритму й аритмії за формулами (4) і (5) статті «Генерування
ритмів», навчає на них нейронну мережу бібліотеки Brain.js і розпізнає введені
послідовності. Результати (зображення в PNG, JPG, BMP, текстовий результат,
набір даних, модель і журнал операцій) зберігаються у файли.


2. Вимоги до середовища
-----------------------

  - Операційна система: Windows 10 / 11, macOS або Linux.
  - Браузер: Google Chrome або Microsoft Edge версії 100 і новіше, Mozilla
    Firefox 100+, Safari 15.4+ (потрібні HTML5 Canvas і елемент <dialog>).
  - Не потрібні: Node.js, npm, локальний сервер, IDE, підключення до
    інтернету. Застосунок відкривається безпосередньо з диска.
  - Бібліотека: Brain.js 2.0.0-beta.24 (ліцензія MIT) уже входить до складу
    застосунку: Аплікація\lib\brain-browser.js. Інших залежностей немає.

Застосунок перевірено в Google Chrome 154 і Microsoft Edge 154 у Windows 11
Pro.

4. Запуск у Windows
-------------------

Спосіб 1 — скрипт start.bat. Відкрийте папку Аплікація і двічі клацніть файл
start.bat. Застосунок відкриється у браузері, який у системі призначено за
замовчуванням. Скрипт виконує такі кроки:

  1. chcp 65001 — вмикає кодування UTF-8, щоб повідомлення українською
     відображалися правильно.
  2. cd /d "%~dp0" — переходить у папку, де лежить сам скрипт (застосунок
     можна розмістити будь-де, зокрема в шляху з кирилицею).
  3. Перевіряє наявність index.html; якщо файлу немає — виводить повідомлення
     про помилку і чекає натискання клавіші.
  4. Перевіряє наявність бібліотеки lib\brain-browser.js так само.
  5. Якщо скрипт запущено з параметром --check (start.bat --check у командному
     рядку), лише повідомляє, що файли на місці, і завершується — так можна
     перевірити комплектність без відкриття браузера.
  6. start "" "%~dp0index.html" — відкриває сторінку в браузері за
     замовчуванням.

Лістинг 1 — Файл start.bat

    @echo off
    chcp 65001 >nul
    cd /d "%~dp0"
    if not exist "index.html" (
      echo [ПОМИЛКА] Не знайдено index.html поруч із start.bat.
      pause
      exit /b 1
    )
    if not exist "lib\brain-browser.js" (
      echo [ПОМИЛКА] Не знайдено бібліотеку lib\brain-browser.js.
      pause
      exit /b 1
    )
    if /i "%~1"=="--check" (
      echo [OK] Файли застосунку на місці: index.html, lib\brain-browser.js
      exit /b 0
    )
    echo Відкриваю застосунок у браузері...
    start "" "%~dp0index.html"
    exit /b 0

У самому файлі start.bat після рядка chcp є ще коментарі (рядки rem) з описом
скрипта; у лістингу їх пропущено.

Спосіб 2 — вручну. Двічі клацніть файл index.html або перетягніть його у вікно
браузера. Щоб відкрити сторінку в певному браузері, клацніть файл правою
кнопкою миші і виберіть «Відкрити за допомогою».


5. Запуск у macOS і Linux
-------------------------

У терміналі перейдіть у папку Аплікація і виконайте команди:

    chmod +x start.sh
    ./start.sh

Скрипт переходить у свою папку, перевіряє наявність index.html і
lib/brain-browser.js та відкриває сторінку командою xdg-open (Linux) або open
(macOS). Також можна просто відкрити index.html у браузері.


6. Перевірка, що застосунок працює
----------------------------------

Після відкриття сторінки в журналі операцій (праворуч) з'являється запис
«Застосунок запущено. Бібліотеку brain.js 2.0.0-beta.24 завантажено.». Якщо
замість цього під шапкою видно червоне повідомлення «Не вдалося завантажити
бібліотеку brain.js», перевірте, що папка lib лежить поруч з index.html.


7. Швидкий старт
----------------

  1. Крок 1. Натисніть «Згенерувати дані» (за замовчуванням 1 000
     послідовностей). Прогрес-бар покаже хід генерації, з'являться зведення,
     діаграма і приклади.
  2. Крок 2. За потреби змініть кількість епох і швидкість навчання та
     натисніть «Навчити мережу». Прогрес-бар оновлюється після кожної епохи;
     після навчання автоматично виконується оцінювання на тестовій вибірці.
  3. Крок 3. Натисніть, наприклад, «Приклад зі статті: аритмія» або введіть
     свою послідовність ЧСС (напр. 72, 68, 75, 71, 69) і натисніть
     «Розпізнати».
  4. Збережіть зображення (PNG / JPG / BMP), результат (.txt) або журнал
     (.txt) відповідними кнопками. Довідка та технічна інформація — кнопки
     «Довідка» й «Інформація» у шапці.


8. Де шукати збережені файли
----------------------------

Застосунок зберігає файли через браузер, тому вони потрапляють у папку
завантажень браузера (зазвичай C:\Users\<ім'я>\Downloads). Імена файлів
містять дату й час, наприклад rhythm_arrhythmia_2026-10-01_20-36-23.png,
rhythm_model_4-8-2_….json, rhythm_log_….txt. Під час першого збереження
кількох файлів поспіль браузер може запитати дозвіл на «завантаження кількох
файлів» — його слід надати.
